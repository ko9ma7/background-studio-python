# 전문 편집 파이프라인

이 프로젝트의 편집값은 단순 화면 효과가 아니라 배경 제거 모델이 만든 **알파
마스크와 피사체 외곽**을 기준으로 계산한다.

## 처리 순서

1. AI가 원본에서 피사체 알파 마스크를 만든다.
2. 마스크의 실제 바운딩 박스를 찾아 중앙 정렬, 배율, X/Y 위치를 적용한다.
3. 피사체 RGB에 밝게, 선명하게, 웜, 쿨, 흑백, 코믹 필터를 적용한다.
4. 출력 레이어를 고른다.
   - `composite`: 피사체, 배경, 그림자를 합친 완성 이미지
   - `mask`: 흰 피사체와 검은 배경의 불투명 마스크
   - `outline`: 알파 마스크의 팽창·침식 차이로 만든 투명 외곽선
5. 이미지 또는 각 동영상 프레임을 같은 값으로 저장한다.

코믹 필터의 굵은 내부 선은 RGB 명암 경계에서 계산하고, `outline`의 실루엣
외곽선은 알파 경계에서 계산한다. 따라서 두 효과를 구분해 사용할 수 있다.

## 권장값

| 목적 | 마스크 기준 | 부드러움 | 외곽선 | 배율 | 추천 출력 |
|---|---:|---:|---:|---:|---|
| 상품 사진 | 0.45~0.60 | 0.08~0.18 | 1~3px | 90~110% | PNG/WebP |
| 인물·머리카락 | 0.35~0.50 | 0.15~0.30 | 1~2px | 90~105% | PNG |
| 스티커 | 0.50~0.65 | 0.05~0.15 | 4~8px | 80~100% | PNG/SVG |
| 코믹 하이라이트 | 0.45~0.60 | 0.08~0.20 | 2~5px | 90~120% | PNG/MP4 |
| 편집기 전달용 마스크 | 0.45~0.60 | 0.05~0.15 | 해당 없음 | 100% | PNG/TIFF |

`subject_offset_x/y`는 캔버스 폭과 높이에 대한 비율이다. `0.1`은 오른쪽 또는
아래로 10% 이동한다. 자동 중앙 정렬은 매 프레임의 마스크 중심을 사용하므로
영상에서는 피사체가 크게 변할 때 미세한 흔들림이 생길 수 있다.

## 저장 형식 판단

- 투명 이미지: PNG 또는 WebP
- 사진 전달: JPEG(투명 영역은 흰색으로 합성)
- 무손실 편집 전달: TIFF 또는 PNG
- 실제 벡터 외곽 패스: 이미지의 `outline + SVG`
- 투명 영상: WebM VP9 또는 MOV ProRes 4444
- 호환 영상: MP4 H.264
- 짧은 반복: GIF

SVG는 알파 경계를 벡터 경로로 바꾼 결과다. Photoshop의 펜 도구처럼 베지어
핸들을 직접 미세 조정하는 기능은 아니므로 로고·인쇄용 최종 패스는 Illustrator,
Inkscape 또는 Photoshop에서 마지막 노드를 정리하는 것이 좋다.

## 영상 선택

- WPF: FFmpeg를 앱 전용 폴더에 자동 설치하므로 일반 Windows 편집에 적합하다.
- Python: 길이 제한이 없고 오디오를 유지해 서버·배치 작업에 가장 적합하다.
- Web: 15초 고정 제한은 없으며 내부적으로 15초 구간씩 순차 처리해 하나의
  파일로 만든다. 다만 결과 버퍼와 AI 모델이 브라우저 메모리를 사용하므로
  긴 영상은 WPF 또는 Python을 권장한다.

FFmpeg는 동영상 컨테이너를 읽고 프레임을 추출한 뒤 MP4, WebM, MOV, GIF로
다시 묶는 미디어 엔진이다. AI 배경 제거 모델과는 별개이며, WPF 빌드는
다운로드 ZIP의 SHA-256을 확인한 다음 `%LOCALAPPDATA%\BackgroundStudio\ffmpeg`
아래에서 실행한다.
