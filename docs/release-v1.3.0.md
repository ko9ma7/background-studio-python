# Background Studio Python 1.3.0

## 달라진 점

- API 상태창 대신 C#판과 같은 완성형 Windows 데스크톱 편집기를 제공합니다.
- 이미지·동영상 파일 대기열과 순차 일괄 변환을 지원합니다.
- 큰 미리보기와 배경, 필터·외곽, 위치·크기, 고급, 저장 탭을 제공합니다.
- PNG, JPEG, WebP, BMP, TIFF, SVG와 MP4, WebM, MOV, GIF를 선택합니다.
- 결과를 자동으로 고유한 이름에 저장하고 결과 파일·저장 폴더를 바로 엽니다.
- 분리된 피사체를 재사용해 편집값 변경 시 AI 분석을 반복하지 않습니다.
- 영상 처리 시 FFmpeg 8.1.2를 내려받고 SHA-256을 검증합니다.
- 처리 취소, 선택 삭제, 전체 초기화와 오류 상태를 제공합니다.

## 실행

ZIP을 풀고 `BackgroundStudio-Python.exe`를 실행합니다. Python, .NET,
FFmpeg를 별도로 설치할 필요가 없습니다. 첫 AI 처리에서는 선택한 모델이
사용자 캐시에 다운로드됩니다.

## 확인 항목

- Ruff와 Pytest
- 소스 GUI 실행과 주요 탭·버튼 접근
- Windows EXE 빌드 및 실제 실행
- 실제 이미지 배경 제거·필터·자동 저장
- 창 종료 후 프로세스 정리
