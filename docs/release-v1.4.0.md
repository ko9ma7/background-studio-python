# Background Studio Python 1.4.0

## 새 기능

- 세로·대형 이미지 기본 맞춤 보기
- 포인터 중심 휠 확대·축소, 손 도구 팬, 100% 실제 픽셀 보기
- 남은 배경 지우기, 피사체 복원, 브러시 크기, 마스크 실행 취소

## 수정

- 완료 항목만 있을 때 전체 대기열을 다시 처리하던 분기를 제거했습니다.
- 새 파일, 오류, 편집 변경, 마스크 보정 항목만 다음 변환에서 실행됩니다.
- 수동 마스크는 원래 AI 알파에서 매번 재생해 복원 도구가 정확히 동작합니다.

수동 브러시는 이미지 작업용입니다. 동영상은 자동 마스크 후처리 값을
사용합니다.
